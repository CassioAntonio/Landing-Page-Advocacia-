# Site Institucional - Advocacia

Projeto de site institucional desenvolvido para escritório de advocacia.

## 📌 Sobre o projeto

Este projeto tem como objetivo apresentar informações institucionais do escritório, suas áreas de atuação e facilitar o contato com clientes.

## ⚙️ Tecnologias utilizadas

- HTML
- CSS
- JavaScript

## 🎯 Funcionalidades

- Página institucional com apresentação do escritório
- Exibição das áreas de atuação
- Seção de contato
- Layout responsivo para diferentes dispositivos

## 🚧 Status do projeto

Projeto em andamento, em fase de desenvolvimento e melhorias contínuas.
